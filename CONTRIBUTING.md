# Contributing

Thanks for considering a contribution!

## Development setup
1. Create and activate a virtual environment.
2. Install dependencies with `pip install -r requirements-dev.txt`.
3. Run tests with `python -m unittest discover -s tests -v`.

## Pull requests
- Keep the scope focused and explain the reason for the change.
- Add or update tests for feature-engineering or analytics changes.
- Do not commit API credentials, local environment files, generated datasets, or model artifacts.
- Document new configuration options and data-source limitations.
- Never present exploratory indicators as guaranteed predictions or financial advice.
